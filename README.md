# Sudoku SAT Solver
Bu proje, resimdeki Sudoku bulmacalarını Google Gemini API kullanarak algılayan ve Glucose3 SAT solver ile çözen bir uygulamadır.

## Ekip ve Katkılar
- **Siz:** `input_handling.py` (API entegrasyonu ve görüntü işleme) ve `main.py`.
- **Feyza:** `gui.py` (Tkinter arayüz tasarımı ve kullanıcı etkileşimi).
- **İrem:** `sat_encoding.py` ve `sat_solving.py` (Sudoku kısıtlarının SAT formatına dönüştürülmesi).
